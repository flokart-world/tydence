# Frozen Unicode Character Database extracts

These files are frozen verbatim copies of Unicode Consortium
publications. They pin the character tables of tydence manifest
format versions: regenerating a manifest must classify every code
point exactly as the original stamping run did, so these tables must
never follow a dependency or toolchain upgrade. Adopting a newer
Unicode version means adding a new file here and bumping the
manifest format version (see `docs/stamping.md` §4.3).

Do not edit these files. Their integrity is checked against the
digests below, which can be reverified against unicode.org.
